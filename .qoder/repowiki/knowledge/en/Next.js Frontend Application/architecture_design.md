Single-page Next.js App Router application under `frontend/app/`. The root layout (`app/layout.tsx`) registers two Google fonts (Geist Sans + Geist Mono) as CSS variables and applies a full-height flex body; it also exports site metadata. The only route is `app/page.tsx`, which renders the starter landing page using `next/image` for static assets from `public/`. Styling is done exclusively with Tailwind CSS v4 classes consumed through `@tailwindcss/turbopack` in `next.config.ts`, which enables `cacheComponents`, `partialPrefetching`, and a custom `.css` loader rule. There are no pages beyond the home route, no API routes, and no client components — the app is currently a server-rendered template.
